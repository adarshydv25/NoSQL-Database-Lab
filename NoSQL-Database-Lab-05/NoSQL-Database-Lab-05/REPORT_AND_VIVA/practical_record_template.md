## Conclusion
Riak KV stores data as bucket-key-value objects and supports distributed storage,
replication and data types in supported versions. Neo4j stores data as nodes and
relationships and uses Cypher for connected-data queries. Riak is useful for key-based
distributed storage, while Neo4j is useful when relationships are central to the application.
