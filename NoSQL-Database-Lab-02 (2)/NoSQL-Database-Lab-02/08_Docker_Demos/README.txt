DOCKER DEMONSTRATIONS (OPTIONAL ADVANCED TASKS)

These examples are for isolated learning environments. Docker Desktop must be installed
and running. They are not production-ready deployments.

- MONGO_REPLICA_SET_GUIDE.txt: single-server primary/secondary replica set on localhost.
- MONGO_SHARDING_GUIDE.txt: describes a multi-container sharded topology and setup steps.

For an easier assignment demonstration, use the architecture diagrams and explain the
steps, but do not claim replication/sharding is working unless you have verified it.
